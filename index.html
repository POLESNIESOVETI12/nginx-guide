Сайт на RU VPS с Nginx

Один VPS на Ubuntu 24.04, свой домен и один файл HTML. Nginx принимает HTTP на 80 и HTTPS на 443.

1. Домен2. Nginx3. Ваш HTML4. HTTPS

1. Направить домен на VPS

В панели DNS добавьте A-запись с публичным IPv4 российского VPS. Для основного домена имя записи обычно @, для поддомена site.my-domain.example — site. Если уже есть запись AAAA, она должна вести на рабочий IPv6 этого же VPS.

Введите только имя, без https:// и пути. Для кириллицы используйте Punycode. Команды ниже подставят это имя автоматически.

Подключитесь к RU VPS по SSH. Здесь и дальше вставляйте команды в это SSH-окно.

Дальше, когда: команда показала публичный IPv4 вашего RU VPS.

2. Установить Nginx и добавить сайт

Для этой схемы порты 80/TCP и 443/TCP должны быть свободны под Nginx или уже заняты самим Nginx. Если на них работает другой сервис, сначала выберите, где будет размещаться сайт.

Проверьте, что установка завершилась строкой active. Затем добавьте конфигурацию для my-domain.example. Команда создаёт отдельный файл для домена и проверяет синтаксис перед применением.

Дальше, когда: в выводе Nginx есть syntax is ok и test is successful. Сообщение Config already exists означает, что для этого домена уже есть конфигурация и её нужно проверить перед продолжением.

3. Поставить свою HTML-страницу

Вставьте свой HTML в поле или измените короткий пример. Нажмите «Копировать» под полем и вставьте весь блок в SSH. Он запишет /var/www/my-domain.example/index.html и сохранит прежний файл в /var/backups, если он был.

Дальше, когда: локальная проверка вернула HTTP 200, а страница открывается по http://my-domain.example/ с другого устройства. Если браузер сам меняет схему на HTTPS, проверьте HTTP в приватном окне или командой curl -I http://ВАШ-ДОМЕН/ с компьютера.

4. Включить и проверить HTTPS

Certbot выпустит сертификат Let's Encrypt, добавит HTTPS в Nginx и включит переход с HTTP на HTTPS. При первом запуске он попросит почту и согласие с условиями. Для выпуска проверка Let's Encrypt должна достучаться до домена на 80/TCP.

Запустите проверку после успешного выпуска сертификата. Блок также показывает таймер Certbot и проверяет пробное продление.

Готово, когда: вывод начинается с HTTPS 200, пробное продление прошло успешно, а https://my-domain.example/ открывается в браузере с другого устройства.

Если сайт не открывается
  • Открывается стандартная страница Nginx. Проверьте, что заходите по домену и что IP в шаге 1 совпадает с IP RU VPS.
  • Certbot не смог подтвердить домен. Сначала проверьте DNS и доступность HTTP снаружи. В сообщении Certbot ищите домен и причину отказа.
  • Ошибка address already in use. Команда ниже покажет процесс на 80 или 443.

Справка по конфигурации Nginx и проверке домена Let's Encrypt.
